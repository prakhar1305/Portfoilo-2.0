## 🔊 Web Audio API Synthesizer (Zero External Dependencies)

All anime sound effects (Katana slash, Steins;Gate nixie click, Jujutsu Kaisen domain bass rumble, and success chimes) are generated **natively in the browser using the Web Audio API**.
- Zero external audio files or broken links.
- Instant response with sub-millisecond latency.
- Convenient sound **Mute / Unmute toggle** located in the top navbar (persisted in `localStorage`).

## 🌐 Free 1-Click Hosting Guide

When you're ready to share your portfolio with recruiters, professors, and friends:

### Option 1: GitHub Pages (Recommended)
1. Initialize Git and commit the folder:
   ```bash
   git init
   git add .
   git commit -m "feat: anime-themed developer portfolio"
   git branch -M main
   git remote add origin https://github.com/prakhar1305/prakhar1305.github.io.git
   git push -u origin main
   ```
2. In your GitHub repository, go to **Settings ➔ Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your website will be live worldwide at: `https://prakhar1305.github.io`!

### Option 2: Vercel or Netlify
- Drag and drop the `prakhar-portfolio` folder directly into [netlify.com/drop](https://app.netlify.com/drop) or import your GitHub repo on [vercel.com](https://vercel.com) for instant free SSL and a custom `.vercel.app` URL.
